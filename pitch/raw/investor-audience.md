# Audience: student competition judges (raw)

*Knowledge-Based for judging criteria. Typical rubrics, not one specific competition. Check the real rubric.*

Student startup and app competitions usually score:
- **Problem clarity:** is it real, and is it felt by the team? A founder's own problem counts as evidence.
- **Solution / demo:** does it work? A live demo outweighs slides.
- **Innovation:** what's different from existing apps?
- **Feasibility / execution:** what's built, how it's tested, technical depth.
- **Market / impact:** who else has this problem, and how many?
- **Sustainability:** a believable path to keep it running (a business model, even if planned).
- **Presentation:** clarity, timing, Q&A.

Red flags judges call out: "no competition" claims, made-up market numbers, features listed without a user story, overrunning time.

Implication for PACE: lead with the lived problem plus a working demo. Be honest about zero users. Show the engineering (tests, offline, pure scheduling logic). Give one honest sustainability path.
